- 🎯 Qualidade de software, automação de testes e boas práticas de código
- 📱 Desenvolvimento mobile com **Swift/SwiftUI** (iOS) e **Kotlin** (Android)
- ♿ Interesse especial em UX, acessibilidade e experiência do usuário
- 🌱 Estudando: aprofundamento em iOS, pipelines CI/CD para QA e App Store Connect
